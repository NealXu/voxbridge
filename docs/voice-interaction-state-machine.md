## 状态定义

| 状态 | 触发事件 | 显示内容 | 后续状态 |
|------|---------|---------|---------|
| READY | F9 按下 | "就绪，按 F9 说话（Ctrl+C 退出）" | RECORDING |
| RECORDING | F9 释放 | "🎙 录音中…（松开结束 / Esc 取消）" | PROCESSING |
| RECORDING | Esc | - | CANCELLING |
| PROCESSING | STT 完成 | "语音输入成功，识别中…" | EDITING |
| PROCESSING | 超时/错误 | 错误信息 | READY |
| CANCELLING | (立即) | "已取消" → "就绪，按 F9 说话（Ctrl+C 退出）" | READY |
| EDITING | Enter | 识别文本发送 | AGENT_RUNNING/READY |
| EDITING | Esc | "已取消" → "就绪，按 F9 说话..." | READY |
| EDITING | Ctrl+U | 清空缓冲区 | EDITING (继续) |
| EDITING | Backspace | 删除末字符 | EDITING (继续) |
| EDITING | 字符输入 | 替换/追加 | EDITING (继续) |

## UI 显示规范

### 识别编辑界面 (EDITING)

```
🎤 写一个hello world程序并运行
(Enter 发送 / Esc 取消 / Ctrl+U 清空)
```

- **第一行**: 识别文本（可编辑），绿色
- **第二行**: 操作提示，灰色 DIM

### 状态提示格式

| 状态 | 格式 |
|------|------|
| READY | 黄色，单行 |
| RECORDING | 黄色，单行 |
| PROCESSING | 黄色，单行 |
| CANCELLING | DIM "已取消" → READY 提示 |
| EDITING | 绿色文本 + DIM 提示，两行 |

## 键盘输入处理

| 按键 | 字节码 | 动作 |
|------|--------|------|
| Enter | 0x0d / 0x0a | 确认发送 |
| Esc | 0x1b | 取消 |
| Ctrl+U | 0x15 | 清空缓冲区 |
| Backspace | 0x7f / 0x08 | 删除末字符 |
| 可打印字符 | - | 首次替换，后续追加 |

## 实现要点

1. **状态转换延迟**: CANCELLING 状态需要短暂显示 "已取消" 后再显示 READY 提示
2. **光标覆盖**: 使用 `\r\x1b[K` 清除当前行，确保 READY 提示覆盖 "已取消"
3. **两行编辑界面**: 识别文本和操作提示分行显示，便于用户聚焦文本
4. **编辑模式光标**: 文本末尾应有光标，支持实时编辑反馈
