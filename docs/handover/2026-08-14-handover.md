## 1. 项目概述

按住 **F9** 说话 → 本地 `faster-whisper`(large-v3) 将中文语音转成文本指令 → 经 `@anthropic-ai/claude-agent-sdk` 送入持久会话（走 DeepSeek 网关）→ 终端流式显示 agent 回复与工具调用。全程静默，无 TTS。

## 2. 架构

```
┌────────────────────────────────────────────────────┐
│ Node.js 主进程 (TypeScript, src/)                   │
│  触发模块(trigger) → 会话管理器(session) → 终端UI(ui) │
│                         │ JSONL over stdio          │
├─────────────────────────┼──────────────────────────┤
│ Python STT worker (stt_worker/)                    │
│  Recorder(录音) → VAD(端点检测) → WhisperEngine(识别)│
└────────────────────────────────────────────────────┘
```

- 语音管道在 Python 侧闭环，Node 只拿到最终文本。
- 通信协议为 stdio JSONL、UTF-8、`\n` 结尾。
- 触发模块可插拔：`trigger.global=true`（全局热键 hold-to-talk，依赖原生模块）/ `false`（终端内 F9 切换 + Esc 取消）。

## 3. 技术栈与依赖

| 层 | 技术 |
|---|---|
| 主进程 | Node 24 + TypeScript 7 + `@anthropic-ai/claude-agent-sdk@^0.3.231` + `node-global-key-listener@^0.3.0`（tsx 运行） |
| 语音 | Python 3.12 + `faster-whisper` + `sounddevice` + `numpy` |
| 模型 | `Systran/faster-whisper-large-v3`（**实际 3.08 GB**，`D:\Models\faster-whisper-large-v3\model.bin`） |
| 测试 | Node `node:test`（tsx 加载）、Python `pytest` |

## 4. 目录结构

```
src/                 Node 主进程
  config.ts          配置加载（带默认值合并）
  env.ts             读取 ~/.claude 与项目 .claude 的 settings env 块
  main.ts            装配入口
  session/           Agent 会话管理器（query 循环、流式 delta、resume、reset）
  stt/               STT 客户端（spawn worker、JSONL 编解码、waitReady/dispose）
  trigger/           触发模块（全局热键 / 终端切换）
  ui/                ANSI 终端 UI
stt_worker/          Python worker
  main.py            stdio 协议循环（start/stop/quit）
  recorder.py        sounddevice 录音
  vad.py             能量端点检测
  whisper_engine.py  faster-whisper 封装
  protocol.py        JSONL 编解码
tests/               Node 测试 + Python 测试（tests/python/）
scripts/             setup-env.ps1、download-model.py、smoke-session.ts、e2e.ts
docs/                superpowers 设计/计划 + 本交接文档
```

## 8. 遗留问题

### 高优先级
1. **真实语音链路未经端到端验证**。`scripts/e2e.ts` 只验证了「文本直发 agent」，语音→识别→agent 全链路尚无成功记录。建议跑 `npm start` 手动验证：按 F9 说话 → 识别 → agent 执行（如建文件）→ 第二句确认会话续接 → Esc 取消。
2. **Whisper 集成测试从未运行**。模型已下载但 2 个 `integration` 测试默认跳过，引擎能否加载 3GB 模型未确认。跑 `-m integration` 验证。

### 中优先级
3. **Worker 崩溃后无恢复**。设计文档承诺「崩溃自动重拉起、连续 3 次失败退出」，实际 `handleWorkerExit()` 后客户端永久失效，`main.ts` 不重启、不提示，只能重启应用。
4. **惰性配置项**（已定义未消费）：
   - `ui.showRecognition` — `main.ts` 无条件打印识别文本
   - `trigger.mode` — `createTrigger` 只用 `trigger.global`
   - `stt.plugin` — 恒用 whisper，二期插件注册表未实现
5. **设计文档承诺但未实现的行为**：麦克风不可用时不列设备报错退出；模型未下载时不自动下载（需手动 `scripts/download-model.py`）；识别文本发送前「可 Ctrl 修改后 Enter」实际自动直发。
6. **全局热键模式下 Esc 取消失效**。`createGlobalTrigger` 不处理 Esc，`onCancel` 仅在终端切换模式（`global:false`）下会触发。

### 低优先级
7. **README 标题仍为 `# Voice-CC`**，项目已改名 voxcode，文档未同步。
8. **会话续接仅限单次进程内**（`lastSessionId` 存内存），跨重启不保留。
9. **模型体积口径不一**（README ~2.9GB / 计划 1.5GB / 实际 3.08GB）；`waitReady(30000)` 30s 超时在慢磁盘上加载 3GB 模型可能不够。

## 9. 关键注意事项

- `options.env` 必须 `{ ...process.env, ...覆盖项 }` 整体替换，否则丢失系统环境变量。
- 模型档位需全钉死（DeepSeek 单模型网关）：`ANTHROPIC_MODEL` + `ANTHROPIC_DEFAULT_OPUS/SONNET/HAIKU_MODEL`。
- worker 侧必须强制 UTF-8（Windows 中文系统 locale 为 cp936，Node 按 UTF-8 读会乱码）。
- 二期方向（设计文档 §10）：唤醒词触发、Chrome Web Speech API 插件、危险操作按键确认细化、ink TUI。
