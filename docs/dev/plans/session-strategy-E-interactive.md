# 方案 E：交互式切换 (Interactive Switch)

**用途：** 设计文档，作为开发参考  
**用户指令：** 将方案A-E均生成细化的md文档

## 概述

运行时通过语音动态切换 session 或目录。

---

## 支持的语音指令

```
切换类：
- "切换到 [项目名]"
- "回到上一个项目"
- "用 [session名] session"

创建类：
- "创建 session [名字]"

查询类：
- "列出所有 session"
- "当前在哪个项目"

管理类：
- "关闭 [session名]"
- "确认" / "取消"
```

---

## 场景示例

```
09:01  [按 F9] "切换到 my-app"
       → ✅ 已切换到 my-app

09:03  [按 F9] "创建 session api-重构"
       → ✅ 已创建 session "api-重构"

09:05  [按 F9] "列出所有 session"
       → 显示 session 列表

09:06  [按 F9] "关闭 api-重构"
       → ⚠️ 确认关闭？
       → [按 F9] "确认"
       → ✅ 已关闭
```

---

## 优缺点

| 优点 | 缺点 |
|------|------|
| ✅ 最灵活 | ❌ 实现复杂 |
| ✅ 语音原生支持 | ❌ 需语音识别准确 |
| ✅ 用户完全控制 | |

---

## 适用场景

- ✅ 语音交互场景
- ✅ 需要动态切换
- ✅ 用户习惯语音控制
- ❌ 静默环境 → 方案 A
